# Fonts

The styles the dashboard renders are listed below, each with its SIL Open Font
License 1.1 text (the OFL requires the license + copyright notice to accompany
redistributed font files; it does **not** require shipping unused styles). The
non-Mini DSEG7 Modern faces are kept as alternates.

| File | Family / style | Used for | License |
|------|----------------|----------|---------|
| `DSEG7ModernMini-Italic.ttf` | DSEG7 Modern Mini Italic | 0–99 tach readout | `DSEG-LICENSE.txt` |
| `DSEG7ModernMini-BoldItalic.ttf` | DSEG7 Modern Mini Bold Italic | dollar amounts + reset date/time | `DSEG-LICENSE.txt` |
| `RobotoCondensed-BoldItalic.ttf` | Roboto Condensed Bold Italic | labels / messages | `RobotoCondensed-OFL.txt` |
| `DSEG7Modern-Italic.ttf` | DSEG7 Modern Italic | alternate (not wired) | `DSEG-LICENSE.txt` |
| `DSEG7Modern-BoldItalic.ttf` | DSEG7 Modern Bold Italic | alternate (not wired) | `DSEG-LICENSE.txt` |
